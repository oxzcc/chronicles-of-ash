# Визуальный стиль

Утверждён по макетам (ноябрь 2026): https://claude.ai/artifact/Kgi8qrhf44CxBxVfPaaRe3. Код стиля — `packages/images/src/style.ts`; при правке промпта обновляй и этот файл.

## Стилевой префикс

```
dark fantasy painterly illustration, oil painting texture, muted earthy palette with ember orange accents,
detailed but soft brushwork, in the style of a classic CRPG character art, no text, no watermark, no signature
```

## Портреты (герой, NPC)

Конвейер: **генерация → вырезание фона → свет → webp с прозрачностью**.

- Рисуются на **ровном светло-сером фоне** и с **ярким светом на лице**: так фон чисто вырезается, а персонаж потом светлее тёмной сцены и легко читается.
- Модель: FLUX.2 [klein] 4B, квадрат 1024 (около 2 с; Kontext [pro] давал 4–6 с и разный кадр; в 3:4 широкие плечи упирались в края). Вырезание: BiRefNet v2 (`Portrait`).
- Кадр один для всех: по пояс, голова в верхней трети с запасом сверху. Если силуэт упёрся в верх или бока (`clippedShare` > 3%) — одна перерисовка с другим seed.
- Холст не обрезается по силуэту: один кадр у всех даёт один масштаб на экране.
- Постобработка (sharp): чистка полупрозрачного ореола, обрезка по силуэту, +18% яркости, +8% контраста.
- Тёплый контур и тень рисует CSS (`drop-shadow`), а не картинка — его легко подстроить.
- Описание внешности NPC мастер даёт в поле `look`; служебная модель переводит его в английский промпт.
- Портрет NPC рисуется один раз при первой встрече и дальше переиспользуется — так NPC узнаваем во всех сценах.

## Четыре облика героя

Один промпт с разными seed даёт почти одинаковые картинки. Поэтому служебная модель пишет **четыре разных образа** на общей основе (раса, класс, пол, заметки игрока): разные возраст, волосы, черты лица, приметы, деталь одежды, выражение. Если модель не ответила — запасной набор из `describe.ts`.

## Фоны локаций

- Широкий кадр без людей, 16:9. Модель: FLUX.2 [klein] 4B.
- Постобработка: −18% яркости, −10% насыщенности; на экране — ещё тень за говорящим. Фон всегда темнее персонажа.
- Общая библиотека: до 3 вариантов на тип локации, общие для всех игроков. Свой фон — только у стартовой и финальной локации квеста.
- Время суток — по типу места (таверна, храм, пещера — ночь; остальное — сумерки, ночь или день).

## Экран

- Сцена = фон локации на весь экран; говорящий — крупный бюст слева, приглушённый, когда звучит голос рассказчика.
- Окно реплики с двойной золотой рамкой и табличкой «Имя / роль»; голос рассказчика — то же окно без таблички, курсивом.
- Шрифты: Cormorant Garamond (имена, заголовки), Alegreya (текст), Alegreya Sans (интерфейс) — все с кириллицей.
