# Визуальный стиль

> Черновик. Задача фазы 0 — выбрать 5–10 картинок-референсов, которые нравятся, и утвердить стилевой префикс. Референсы кладём в `docs/style-refs/` (свои картинки или сгенерированные этим же префиксом).

## Стилевой префикс (английский — FLUX понимает его лучше)

```
dark fantasy painterly illustration, oil painting texture, muted earthy palette with ember orange accents,
dramatic chiaroscuro lighting, drifting grey ash in the air, detailed but soft brushwork,
in the style of a classic CRPG character art, no text, no watermark
```

## Портреты

- Поясной портрет, три четверти, нейтральный тёмный фон с тёплым краевым светом.
- Соотношение 3:4, 768×1024.
- Промпт: `<префикс>, portrait of <раса> <пол> <класс>, <внешность из выбора игрока>, <одежда и снаряжение класса>`.
- Смена эмоции NPC — через Kontext с портретом-референсом: `same character, now <angry|afraid|smiling>, keep face and clothing identical`.

## Фоны локаций

- Широкий кадр без людей, 16:9, 1344×768.
- Библиотека по типу локации × время суток (день, сумерки, ночь): 12 типов × 3 = 36 базовых фонов, общих для всех игроков.
- Уникальный фон — только для финальной локации квеста и ключевых мест.

## Что проверить на референсах

- Узнаётся ли один NPC в трёх разных сценах.
- Читаются ли портреты на тёмном фоне интерфейса.
- Не уходит ли стиль в аниме, фотореализм или «стоковое фэнтези».
